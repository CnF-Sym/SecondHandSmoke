    Library

    Everything this program has ever copied, across every shoot day. Read-only: searching here never changes a card's verdict.

    Every row shows two numbers. Verified is how many separate physical drives the file was read back and checksum-matched on — a fact from the catalog, true whether or not anything is plugged in. Present is how many of those drives are connected right now and still have a file of the right size at the right path. Present is a size check, not a checksum, and it is never higher than verified. Two verified and none present just means the drives are on a shelf.

    Search, or run an audit.

    Catalog

    The catalog is this program's record of every file, hash and drive. Losing it does not lose footage — your media and manifests are on the drives, and the format gate reads the catalog rather than the other way round — but it loses the library, the gate's history and every sync decision. A backup is taken automatically before any upgrade; this is the button for every other time.

    Drive tools

    How fast is this drive, and what is already on it. The speed test writes its own scratch file and removes it; indexing only reads. Neither changes anything about a card.
